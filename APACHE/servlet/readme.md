# Java Servlet Practicals

A collection of Java Servlet practical programs developed as part of Advanced Java coursework.

## Technologies Used

* Java
* Java Servlets
* Apache Tomcat
* HTML
* HTTP

## Concepts Covered

* Servlet Lifecycle
* Handling HTTP Requests and Responses
* `doGet()` and `doPost()`
* Form Data Processing
* Servlet Configuration and URL Mapping

## How to Run

1. Open the project in VS Code.
2. Configure Apache Tomcat.
3. Deploy the application to Tomcat.
4. Start the server and open the application in your browser.
